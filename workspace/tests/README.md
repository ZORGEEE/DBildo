# Проверка демонстрационного пайплайна

После запуска `orders_to_clickhouse` сравните четыре записи по `id` и `amount`
в PostgreSQL `public.orders` и ClickHouse `default.orders FINAL`.

Для проверки работы агента в dev измените тип или имя столбца только в копии
демонстрационной схемы, запустите DAG повторно и попросите агента найти причину.
